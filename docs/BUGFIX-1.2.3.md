# CodeMentor 1.2.3 导师请求与加载反馈修复

发布日期：2026-08-24。

## 修复内容

连接测试只要求模型返回极短的 `OK`，而真实评审需要生成和校验结构化教学结果。此前两者共享 30 秒完整响应上限，因此可能出现“设置页测试成功，实际使用固定超时”。1.2.3 将策略拆分为：

- 连接测试：30 秒；
- 评审、解释、修改验证、追问和小练习：120 秒；
- TCP/TLS 连接建立：仍为 10 秒；
- 超时与取消：继续同步取消本地 Future 和响应正文订阅。

响应安全边界没有放宽：完整 HTTP 正文仍最多 2 MiB，`message.content` 仍最多 64 Ki 个字符。

## 加载动效

导师侧栏状态行新增一个 IntelliJ 原生小型加载图标。它固定占用一个很小的槽位，空闲时不绘制，避免文字和按钮来回移动。以下操作进行中会显示：

- 评审与解释；
- 修改验证、追问和小练习；
- 学习统计读取、Markdown 复习清单导出和本地历史清理。

成功、失败、取消或面板关闭后都会恢复空闲。即使 Tool Window 在后台隐藏时任务结束，重新打开也不会残留错误动画。

## 升级

在 `Settings / Preferences → Plugins → Install Plugin from Disk...` 选择 `code-mentor-1.2.3.zip` 并重启 IDEA。现有设置、PasswordSafe API Key、项目授权和本地学习记录保持不变。

完整验证结果和安装包 SHA-256 见 [安装指南](INSTALL.md#123-发布验证状态)。
